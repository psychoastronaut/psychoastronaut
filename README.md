Senior ML engineer obsessed with LLMs, evals and agents that run on hardware you actually own.

## What I build

- **LLM / GenAI systems** and the evals that tell you whether they work (DSPy, GEPA, prompt optimization)
- **Local-first coding agents**: big models squeezed onto consumer GPUs, wired into real tools
- **Self-hosted everything**: home servers, pipelines, small tools that stay out of the cloud
- Games in Godot, when the brain wants a break
